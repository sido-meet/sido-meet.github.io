AI Agent 长时间工作实践思考

作者：SIDO 2026-05-13
138 字 1 分钟阅读 本机阅读 0 次
Agent OpenClaw 长任务

目的是让AI以一个目标，长时间工作完成任务。计划是以一个idea为出发点，让大模型自行设计框架，运行实验，根据实验结果反馈修正框架，提高实验结果。

实现方案：

  • Openclaw定时每十分钟启动，发送消息给claude code，让其继续工作
  • claude code负责撰写代码，进行实验，优化指标。

结果：

  • 随着代码越来越复杂，claude code愈发难以维护代码。
