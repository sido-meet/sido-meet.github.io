Skill是什么？

Skill 指的是指导大模型完成某项特定任务的指导文档。

  • 没有 skill：大模型会凭借自己的经验做做事情，这很可能做不好，胡乱探索，不符心意。
  • 有 skill：大模型可以根据一套指导规则做事，可以在一定程度的可控下运行，完成任务。

Skill适合什么场景？

可复用的场景，这可以是一切场景，只要你经常需要他做重复的任务，可以是说话语气的回复技巧，也可以重复的模板化论文撰写。

可复用意味着需要判断是不是当前这个任务未来会被重复使用，如果不是请不要创建 skill，skill会带来三种代价：

  1. 创建 skill
  2. 管理 skill
  3. 上下文消耗

怎么使用skill？

对话触发，Agent根据当前对话和 skill 元数据，自行判断是否需要使用 skill。

所以 Description 是触发机制，并非简介。

  • Agent 不会自动查所有 skill，它只看 available_skills 列表中的 description 来决定是否调用
  • Agent 有 undertrigger 倾向（该用时不用）→ 所以 description 必须”pushy”，同时对话中可以明确指出让 Agent 用什么 skill。
  • ❌ “How to build dashboards.”- ✅ “How to build dashboards. Make sure to use this skill whenever the user mentions dashboards, data visualization, internal metrics…”
