背景

功能：在git开发中让ai coding可以并行开发，而不冲突

  1. 想要修改项目部分
  2. 想要修改科研部分

在同一分支下工作会会发生下面的情况

  • 文件覆盖
  • git 状态混乱
  • 一个 agent 看到另一个 agent 未完成的代码
  • merge 非常痛苦

    Note: 这个问题的前提是在同一个工作目录，如果在不同的工作目录下面拉取代码进行分支开发是不会由上面的问题

实际：

  • 有自己的 git 状态

但是：

  • 共用 Git 对象
  • 不需要重新 clone
  • commit 后可以正常 merge
